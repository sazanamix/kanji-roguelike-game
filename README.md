# 漢字ローグ

自分も敵も宝もすべて漢字一文字。元祖 Rogue(1980年)へのオマージュとして作った、
操作不要・全自動で進行するローグライク・シミュレーションです。放置ゲームというより、
ダンジョン探索の自動シミュレーションに近い作りになっています。迷宮は全99階、
99階の階段にたどり着くとクリアとなり、簡単なスタッフロールの後、また1階から
新しい冒険が自動的に始まります。

**公開URL:** https://sazanamix.github.io/kanji-roguelike-game/

## 特徴

- 探索・戦闘・アイテム取得・階段の昇降まで、すべて自動で進行(見ているだけで遊べます)
- 自分(勇)・モンスター・アイテムなど、画面上の要素はすべて漢字一文字で表現
- 全99階のダンジョンを自動生成。深い階ほど強いモンスターが出現し、10階ごとには
  同tierを強化した精鋭個体が、99階には固有の最強モンスター「神」が待ち受ける
- HP・満腹度・レベル・所持金・装備(武器/防具/指輪)などを常時パネルに表示。冒険の記録(メッセージログ)も流れる
- 歴代の冒険を「到達階 > レベル > ターン数」の順で競う殿堂(ハイスコア)パネルつき
- オートセーブに加えて、手動のセーブ/ロード、リセットに対応(いずれもブラウザの localStorage に保存)
- 最高到達階・総冒険回数・総クリア回数などの記録は、周回をまたいで永続的に蓄積
- 依存パッケージ・ビルドステップなし(素のHTML/CSS/JavaScript、ESモジュール)

## 遊び方

上記の公開URL、またはローカルで起動したページを開くだけです。ボタン操作は以下のみ。

- **一時停止 / 再開**: シミュレーションの進行を止める・再開する
- **速度 x1〜x8**: 進行速度を切り替える
- **セーブ / ロード**: 現在の状況を手動で保存・復元する(オートセーブとは別枠)
- **リセット**: 現在の冒険を中断し、新しい冒険を始める(記録は保持されます)

## 凡例

画面上の要素はすべて漢字一文字です。意味の対応は以下の通り。

| 漢字 | 意味 |
|---|---|
| 勇 | 自分 |
| 段 | 階段(降りる) |
| 壁 | 壁 |
| ・ | 床 |

**モンスター**(色が濃いほど危険。階層が深いほど強い個体が出現します)

| 階層 | モンスター |
|---|---|
| 1〜24階 | 鼠・蝠・蛇・狐 |
| 25〜49階 | 狼・熊・骨・蜘 |
| 50〜74階 | 虎・鬼・妖・蠍 |
| 75〜98階 | 竜・魔・死・幽 |
| 99階 | 神(固有の守護者) |

**アイテム**

| 漢字 | 意味 |
|---|---|
| 金 | 所持金 |
| 薬 | 回復ポーション |
| 飯 | 食料(満腹度を回復) |
| 巻 | 巻物(階に着くと自動使用) |
| 剣 | 武器 |
| 盾 | 防具 |
| 輪 | 指輪 |
| 宝 | レアな大金塊 |

## ローカルで実行する

ESモジュール(`<script type="module">`)を使用しているため、`file://` で直接開くと
動作しません。簡易HTTPサーバーで配信してください。

```bash
python -m http.server 8000
```

起動後、`http://localhost:8000/` にアクセスしてください。

## 技術構成

- 素のHTML / CSS / JavaScript(フレームワーク・ライブラリ不使用、ESモジュールのみ)
- ダンジョンは3×3区画のランダム全域木で生成し、部屋・迷路・素通りの区画を通路でつなぐ
  (到達可能性を構造的に保証)
- 自動探索AIは優先度ベース(拾得 > 隣接する敵を攻撃 > 回復 > 食事 > 探索/階段へ移動)で、
  一定ターン進展がない場合は安全弁として階段へ強制的に向かう
- 乱数はシード付き(mulberry32)。ダンジョン地形用と戦闘/ドロップ用の2系統に分離し、
  セーブデータには地形そのものではなく再生成に必要なシードのみを保持

## 既知の制限

- バックグラウンドタブでは `setInterval` がブラウザにより間引かれるため、進行が遅くなることがあります
- 複数タブを同時に開いた場合、オートセーブは後勝ちになります(同時プレイは想定していません)
